# Web Servers, Clearly Explained

A visual, responsive GitHub Pages blog on web-server basics and the practical differences between Apache HTTP Server and Nginx.

Built for the `sujan6288/firstblog` repository. After pushing, enable **Settings → Pages → Deploy from a branch → main / (root)**. The project site will be available at:

`https://sujan6288.github.io/firstblog/`

## Contents

- `index.html` — complete standalone blog page
- `style.css` — responsive editorial design and dark theme
- `script.js` — scroll progress, reveal effects and theme control
- `assets/` — original SVG diagrams used by the article
